## STAR 自检（每一版都过一遍）

- **S**ituation：业务背景一句话说清（谁、什么规模、什么痛点）
- **T**ask：我的职责边界（我负责哪块，不是「参与」）
- **A**ction：**技术动作要具体到能追问**（数据怎么来的、口径怎么定的、为什么选这个方法、踩了什么坑）
- **R**esult：**数字化结果**（-30%、准确率、耗时、覆盖多少人）—— 数字必须能在面试时讲清出处
- 一句话反问自检：**「面试官问『这个数字怎么算出来的』，我答得上吗？」** 答不上就补口径说明。
