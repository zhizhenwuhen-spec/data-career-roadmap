### 2.1 MySQL 8（第 1 站基础）✅ 已于 09-18 完成

```powershell
winget install --id Oracle.MySQL -e --accept-package-agreements --accept-source-agreements
```

- 装的是 **MySQL Installer**，会弹出图形界面：选 **MySQL Server + MySQL Workbench**（其余组件不用勾）。
- 界面里会让你设 **root 密码 —— 务必记住**（建议记在本地密码管理器，**不要写进本仓库**）。
- winget 源当前版本是 8.4 LTS；`wonderful-sql` 按 8.0 编写，8.4 完全兼容（`SELECT 1` 起步无差别）。
- **验收**：装完开 PowerShell 跑 `mysql -u root -p`，输入密码后执行 `SELECT 1;` 能返回 `1` 即通过。
  - 若提示「mysql 不是内部或外部命令」：去「编辑系统环境变量 → 环境变量 → Path」加上 MySQL 的 bin 目录（默认 `C:\Program Files\MySQL\MySQL Server 8.4\bin`），重开终端即可。

### 2.3 Docker Desktop（第 1 周起 `sql-tutorial` / `pagila` 都要用）✅ 已于 09-21 完成

> ### 📌 Docker 安装复盘（09-20 晚 ~ 09-21 完成，踩坑记录）
> **最终状态**：WSL 2.7.14.0（内核 6.18.33）+ Docker Desktop 4.91.0，引擎跑在 WSL2（`docker-desktop` 发行版），`docker run --rm hello-world` 输出 `Hello from Docker!` ✅，Compose v5.5.1。
> **踩过的坑（备忘）**：
> 1. `aka.ms/wsl2kernel` 给的是 **Win10 旧内核 MSI（5.10.16）**，Win11 26200 装不上（msiexec 1603）→ 正确做法是装 **WSL 2.7.14 MSIX**（`github.com/microsoft/WSL/releases`，走代理下载后 `Add-AppxPackage`）。
> 2. WSL 功能启用后**必须重启电脑**再装 MSIX，否则 `Add-AppxPackage` 会卡死（等待服务）。
> 3. `wsl --status` 在「没有安装任何发行版」时报「错误代码 2」是正常现象，**不是故障**；`wsl -l -v` 能列出即正常。
> 4. **Docker 拉镜像走系统代理**：代理软件必须开着，否则 `connect to registry-1.docker.io ... refused`。代理重启后端口会变，Docker 需要重启一次才会重新读到新端口。
> **日常使用要点**：① 拉镜像前先开代理；② 代理端口变化导致 push/拉镜像失败时，重启 Docker Desktop 或更新 `git config --global http.proxy`。

## 三、GitHub 账号注册 + 建库 + 推送（远程仓库这一步）

> 本仓库本地骨架已完成，**只差远程**。你还没有 GitHub 账号，按下面三步走（全程 15 分钟）：

1. **注册**：打开 https://github.com/signup ，建议邮箱用 `1979542038@qq.com`，用户名自己想一个（会出现在链接里，建议 `拼音-数字` 风格）。
2. **建库**：登录后点右上角 `+` → `New repository`：
   - Repository name：`data-career-roadmap`
   - **Public**（要的就是绿色格子被面试官看到）
   - **不要勾** `Add a README file`（我们已有 README，勾了反而冲突）
   - 点 `Create repository`
3. **推送**：把下面三条命令里的 `<你的用户名>` 换成你的 GitHub 用户名，在仓库目录 `C:\Users\19795\求职\data-career-roadmap` 打开 PowerShell 执行：

```powershell
git remote add origin https://github.com/<你的用户名>/data-career-roadmap.git
git branch -M main
git push -u origin main
```

- 第一次 push 会弹 **Git Credential Manager 浏览器窗口**，点授权登录即可（本机 git 已带此组件）。
- ⚠️ **网络排障（09-18 实测）**：git 默认**不读 Windows 系统代理**，直连 github.com:443 会超时（`Failed to connect to github.com:443`）。本机已配置（代理软件开着才有用）：
  ```powershell
  git config --global http.proxy  http://127.0.0.1:15591
  git config --global https.proxy http://127.0.0.1:15591
  ```
  若某天 push 又超时：先确认代理软件（Clash 类）**正在运行**；代理没开时可用 `git config --global --unset http.proxy`（及 https.proxy）临时直连。push 前可用 `git ls-remote https://github.com/<你的用户名>/data-career-roadmap.git` 自测连通性（有输出或安静退出=通；报 Repository not found=没建库；超时=代理没开）。
- 或者：用 **VS Code** 打开仓库文件夹，点左侧源代码管理 → 首次推送时按提示用浏览器登录 GitHub，一样效果。
- push 成功后：仓库页 `Settings → GitHub Pages` 不用开（纯 md 仓库），直接确认 `Contribution activity` 出现绿色格子即可。
- **以后每天**：学完一条内容就 `git add -A && git commit -m "log: 09-xx <内容>" && git push`（或用 VS Code 图形界面点提交+同步）。
